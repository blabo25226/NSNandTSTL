## 2. 論文から読み取れるアルゴリズム仕様

### 2.1 全体構成

```
入力 x ∈ R^p
    → MLP trunk: z = MLP_θ(x) ∈ R^d   (d ≪ p, σ = ReLU または GELU)
    → EML head:  二分木 T, 深さ D
    → 出力 ŷ = Re[T(z; {α, β, γ})] ∈ R
```

論文 §4.1 の入力記号は `n`（入力次元）だが、本リポジトリでは **p = 変数の数** に合わせる。

### 2.2 EML 演算子（式 1, 15）

```
eml(x, y) = exp(x) - ln(y)     x, y ∈ C
∂eml/∂x = exp(x)
∂eml/∂y = -1/y
```

- 主値枝（principal branch）の複素対数を用いる（Odrzywołek [1] に準拠）
- 実数ターゲットでも内部は複素演算。最終出力は **実部** `Re[·]`

### 2.3 EML 木 head（式 9–10）

- 深さ D の **完全二分木**
- 内部ノード数: `2^D - 1`（いずれも `eml`）
- 葉数: `2^D`
- 葉 `i` の値:

```
ℓ_i(z) = α̃_i + β̃_i · (β_i^T z) + γ̃_i · f_prev
```

**実装方針（論文の曖昧点の解釈）**:

論文式 (11) は `(α, β, γ)` を 3 つのロジットとして softmax し、`α̃ + β̃ + γ̃ = 1` とする。ここで `β` はベクトルなので、**葉ごとにスカラー ロジット 3 個** `(logit_α, logit_β, logit_γ)` を設け、凸結合

```
ℓ_i(z) = w_α · α_i + w_β · (β_i^T z) + w_γ · f_prev
         where (w_α, w_β, w_γ) = softmax(logit_α, logit_β, logit_γ)
```

と解釈する。`f_prev` は親 EML ノードの出力（根に近い葉は 0）。

木の評価は **葉 → 内部ノード（ボトムアップ）→ 根** の順。

### 2.4 記号的スナップ（式 11, §4.2）

1. 学習中: softmax 重み（微分可能）
2. hardening schedule: 温度 τ を下げて頂点に近づける（Gumbel-softmax / 低温 softmax）
3. 最終: `(w_α, w_β, w_γ)` を `{0,1}` にクランプ → 閉形式 EML 式を復元

Odrzywołek [1] / eml-rust では `SEARCH → HARDEN → POLISH → SNAP` の 4 段階が報告されている。本実装でも同様のスケジュールを **オプション** として用意する。

### 2.5 数値安定化（§5.3, §6.2）

| 問題 | 対策 |
|------|------|
| `exp` オーバーフロー | 実部・虚部を `[-C, C]` にクランプ（C はハイパーパラメータ、初期値 20） |
| `ln(0)` 特異点 | 入力に `ε` を加える、`Im(y)` が 0 に近い場合のガード |
| 勾配 NaN | `torch.nan_to_num`、勾配クリッピング（max_norm=1.0） |
| 深さ D ≥ 5 | **非推奨**（成功率 < 1%）。D ∈ {2, 3, 4} のみサポート |

### 2.6 推奨ハイパーパラメータ（論文 + [1] からの初期値）

| パラメータ | 初期値 | 根拠 |
|------------|--------|------|
| trunk 層数 L | 3 | 論文は任意。低次元デモ用 |
| trunk 幅 | 64 | 実装者設定 |
| 特徴次元 d | 4〜8 | 式 (8) d ≪ p |
| head 深さ D | 2, 3 | §5.2, §6.2 |
| 活性化 σ | ReLU | 論文例 |
| 最適化 | Adam | §4.2 |
| 学習率 | 1e-3 | 一般的初期値（要チューニング） |
