## 4. ベースラインゲート評価（本フェーズ）

### 4.1 条件

- ターゲット: Phase 3 の 6 式（Gate A: 5 式、Gate B: `sin_plus`）
- シード: `{0, 1, 7, 42, 123}`
- ノイズ: 1%（`noise_std_rel=0.01`）
- 成功: **symbolic OK** = snapped holdout MSE ≤ 閾値（`SR検証計画.md` 新定義）
- Gate A 合格: 各コア式で **≥ 4/5 seeds（80%）**
- Gate C 合格: Gate A で symbolic OK の run の snap_degrade 中央値 **≤ 1.5**

### 4.2 プロトコル比較（symbolic OK 率）

| target | `full` | `freeze` | `trunk_first` |
|--------|--------|----------|---------------|
| square | **60%** (3/5) | 40% (2/5) | 0% |
| product | **60%** (3/5) | 60% (3/5) | 0% |
| sum | 20% (1/5) | 20% (1/5) | 0% |
| exp | **100%** (5/5) | — | — |
| sin | 40% (2/5) | 40% (2/5) | 0% |
| sin_plus | 20% (1/5) | 20% (1/5) | 0% |

結果ディレクトリ:

| protocol | path | Gate A | Gate B | Gate C |
|----------|------|--------|--------|--------|
| `full` | `results/baseline_gate_20260713_160538/` | FAIL | FAIL | **PASS** |
| `freeze` | `results/baseline_gate_20260713_164957/` | FAIL | FAIL | **PASS** |
| `trunk_first` | `results/baseline_gate_20260713_172906/` | FAIL | FAIL | FAIL |

（`freeze` 実行時は未達ターゲットのみ。`exp` は `full` で既に 100% のため省略。）

### 4.3 観察

1. **シード 0・1 が系統的に不利** — 多くの式で失敗が集中（以前の `sin_plus` 脆弱性と同根）。
2. **シード 42・7 が相対的に安定** — `square`/`product`/`exp` で成功しやすい。
3. **`trunk_first` は全ターゲット 0%** — 本環境では採用不可（trunk のみ SEARCH では head が記号を担えない）。
4. **`freeze` は `full` を上回らない** — `square` は悪化（60%→40%）。
5. **Gate C** — `full`/`freeze` では成功 run の degrade 中央値 **1.0**（スナップはロスレス）。

### 4.4 ゲート判定（計画書 §2 基準）

| ゲート | 判定 | 備考 |
|--------|------|------|
| Gate A | **FAIL** | `exp` のみ 100%。他は 20–60% |
| Gate B | **FAIL** | `sin_plus` 20%（任意項目） |
| Gate D（本報告） | **完了** | 本ファイル |

## 7. TSTL 統合への引き継ぎ

### 7.1 推奨設定

| 項目 | 推奨 |
|------|------|
| 学習プロトコル | `full`（`OdrzywolekPipelineConfig` 既定 + 式別 HP） |
| 層寄与プロファイル用ターゲット | **`exp`（第一候補）**、`product`（第二候補） |
| プロファイル用シード | **42, 7**（ゲートで安定） |
| trunk 層 API | `MLPTrunk.linear_layers()` / `set_trainable_linear_layers()` 実装済み |

### 7.2 Gate A 未達の扱い

- TSTL の `C(k)` は「SR 成功率」ではなく **層 k だけ更新したときの損失改善** を測る。
- よって **Gate A 未達は TSTL 着手をブロックしない**が、プロファイル実験は **安定 run が出るターゲット/シードに限定**する。
- 統合実験の成功指標は別途定義（例: Only Bk が full trunk 学習と同等 MSE、学習時間短縮、NaN 率低下）。

### 7.3 次ステップ

1. `TSTL/texts/作業計画書.md` — `C(k)` 最小実装
2. `NSN/scripts/trunk_layer_profile.py` — trunk 3 層の層寄与
3. Only Bk vs full trunk 比較（`exp` × seed 42 から）
