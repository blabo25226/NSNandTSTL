# NSN × TSTL — 統合 neuro-symbolic 回帰の研究計画

NSN（DNN-EML ハイブリッド）と TSTL（層選択的学習）を組み合わせ、**高次元データでも解釈可能なシンボリック回帰**を実現するアルゴリズムを開発する。本ドキュメントは研究・実装の計画書である。実装のクイックスタートや API 説明は、Phase 0 完了後に追記する。

参考文献リンクは [`source.md`](source.md) を参照。

---

## 1. 背景と動機

### 1.1 NSN（Neuro-Symbolic Network / DNN-EML）

EML 演算子 `eml(x, y) = exp(x) - ln(y)` は、定数 `1` と組み合わせることで全初等関数を表現できる Sheffer 型プリミティブである。NSN はこれを用い、

- **Stage 1（trunk）**: MLP が高次元入力 `x` を低次元特徴 `z` に圧縮
- **Stage 2（head）**: 浅い EML 木が `z` から予測 `ŷ` を生成し、学習後に記号式へスナップ

という二段構成で、精度と解釈可能性を両立しようとする。

### 1.2 TSTL（Training a Single Transformer Layer）

LLM の RL 後学習において、**単一の中間層だけを学習しても全パラメータ学習と同等以上の改善**が得られることを示した。層寄与 `C(k)` により各層の有効性を定量化し、高寄与層はネットワーク深さの 40–60%（中間層）に集中するという安定した構造が観測された。

### 1.3 なぜ統合するか

| 課題 | NSN 単独の限界 | TSTL から持ち込む解 |
|------|----------------|---------------------|
| 高次元入力 | trunk の全層学習はコスト・不安定 | 高寄与層のみ学習（Only Bk / Mid-k） |
| 記号復元の失敗 | 深い EML 木（D≥5）は学習困難 | trunk を絞って特徴 `z` の質を上げ、浅い head（D≤4）で済ませる |
| ブラックボックス化 | MLP trunk が不透明 | 最終出力は EML 木由来の**ホワイトボックス式** |

## 2. 研究目標

### 2.1 技術目標

1. **DNN-EML + 層選択的学習**の統合アルゴリズムを実装する。
2. TSTL の層寄与概念を **MLP trunk（教師あり回帰）** に転用し、中間層集中が成り立つか検証する。
3. 従来の EML ベース SR が苦手とする **変数の多いデータ**でも、trunk による次元圧縮 + 選択的学習で安定した記号回帰を行う。

### 2.2 応用目標（Phase 4）

**遺伝データ・生体データ**など、ホワイトボックス（説明可能性）が強く求められる領域への適用を見据える。

- 遺伝子発現、タンパク質オミクス、臨床バイオマーカーなど **特徴量が数百〜数万** に及ぶデータ
- 「どの変数が、どの関数形で表型に効いているか」を**人が読める式**として提示したいユースケース
- 従来の EML-SR（低次元・既知の物理式向け）では探索空間と数値安定性の両面で破綻しやすい領域

統合モデルでは **trunk が生物学的に意味のある低次元表現 `z` を学習し、head が `z` 上の簡潔な初等関数式を出力する** という二層の解釈構造を目指す。

## 3. 統合アーキテクチャ（案）

```
入力 x ∈ R^p  (p: 変数の数。例: 遺伝子数・バイオマーカー数)
        │
        ▼
┌─────────────────────────────┐
│  MLP Trunk (L 層)           │  ← TSTL: 高寄与 k 層のみ学習
│  x → h₁ → … → h_L → z ∈ R^d│     (d ≪ p)
└─────────────────────────────┘
        │
        ▼
┌─────────────────────────────┐
│  EML Head (深さ D ≤ 4)      │  ← NSN: 記号的スナップ
│  二分木: eml(·,·) の合成     │     → 閉形式の ŷ = f(z)
└─────────────────────────────┘
        │
        ▼
    予測 ŷ  +  解釈可能な式
```

**層寄与（回帰版）**:

```
C(k) = (M_k - M_base) / (M_full - M_base)
```

- `M`: 負の損失、または R² 等の性能指標（Phase 1 で定義を固定）
- 層 `k` のみ学習し、他層・head を凍結したときの性能から算出

## 4. 開発フェーズ

### Phase 0 — 単独再現（最重要）

両手法を個別に動かし、統合前に実装・数値挙動を把握する。**このフェーズを飛ばさない。**

#### 0-A: NSN 最小実装（`NSN/src/`）

| タスク | 成果物 | 完了条件 |
|--------|--------|----------|
| EML 演算子 | `eml.py` / `EMLNode` | 順伝播・逆伝播が既知式と一致 |
| 数値安定化 | exp クランプ、ln 定義域ガード | 勾配 NaN なしで 1000 step 学習 |
| 浅い EML 木 | D=2, 3 の head | `exp(x)`, `x²` 等の既知関数を回復 |
| MLP trunk | 2〜4 層、ReLU/GELU | 低次元入力で MSE 学習が収束 |
| DNN-EML 結合 | trunk + head 端到端 | Feynman 1 式で overfit デモ |

#### 0-B: TSTL 手順の縮小再現（`TSTL/src/`）

| タスク | 成果物 | 完了条件 |
|--------|--------|----------|
| 層凍結ユーティリティ | `freeze_all_except(layer_k)` | 対象層のみ `requires_grad=True` |
| 層寄与プロファイル | `layer_contribution.py` | 3 層 MLP で C(k) ヒートマップ出力 |
| 比較実験 | 全層 vs 単層 vs 中間層 | 中間層が高い傾向を再現（小規模でも可） |

#### 0-C: 共通基盤（ルート `src/`）

- 設定ファイル形式（YAML 等）
- 実験ログ → `results/` への保存規約
- シード固定・再現性ユーティリティ

**Phase 0 出口基準**: NSN の DNN-EML が低次元で動作し、TSTL 式の層寄与測定が MLP で回ること。

### Phase 1 — 橋渡し：NSN trunk への層寄与適用

| タスク | 内容 |
|--------|------|
| 1.1 | DNN-EML の **trunk 各層**に対して C(k) を測定 |
| 1.2 | head 学習あり/なし、凍結の組み合わせを比較 |
| 1.3 | 中間層集中が NSN trunk でも観測されるか検証 |
| 1.4 | 層寄与と重み変化量 ∥Δθ∥ の相関を確認（TSTL の知見の再現） |

**成功指標**: 全層学習に対し、最良単層または中間層グループで C(k) ≥ 0.8。

---

### Phase 2 — 統合アルゴリズム

以下の戦略を実装し比較する（`src/hybrid/`）。

| 戦略 | 説明 |
|------|------|
| **Full** | trunk 全層 + EML head 全学習（ベースライン） |
| **Only Bk** | 層寄与上位 k 層のみ trunk 学習 |
| **Boost Bk** | 高寄与層の学習率を 2× |
| **Mid-k** | プロファイリング不要。位置ベースで中間 k 層を選択 |
| **Two-stage** | (A) trunk 高寄与層のみ → (B) head 微調整 + 記号的スナップ |

**学習フロー（Two-stage 案）**:

1. ベース DNN-EML を短いウォームアップ
2. 層寄与プロファイル（または Mid-k）で trunk 層を決定
3. 選択層のみで本学習
4. 葉重みの hardening → スナップ → 必要なら head のみ微調整

### Phase 3 — 評価

#### 3.1 ベンチマーク（段階的）

| 段階 | データ | 目的 |
|------|--------|------|
| 低次元 | Feynman DB（NSN 準拠） | 記号回帰精度・スナップ成功率 |
| 中次元 | 合成式 + ノイズ（p=10〜50） | 高次元化に向けたスケーリング挙動 |
| 高次元 | 公開オミクス（後述） | 応用前の実データ検証 |

#### 3.2 評価指標

| カテゴリ | 指標 |
|----------|------|
| 予測精度 | MSE, MAE, R² |
| 記号回帰 | 式一致率、スナップ成功率、式の複雑度（ノード数） |
| 学習効率 | 収束 step 数、GPU 時間、更新パラメータ数 |
| 解釈性 | 復元式の項数、変数依存の明確さ |
| ロバスト性 | ノイズ・欠損・train/test 分割での劣化 |

#### 3.3 比較手法

- 全層 DNN-EML（NSN ベースライン）
- 素の MLP
- EQL / PySR 等の古典的 SR（可能な範囲で）
- trunk なし直接 EML-SR（高次元で失敗する対照群として重要）

### Phase 4 — 応用：遺伝・生体データへのホワイトボックス SR

#### 4.1 問題設定

**記号**: `n` = **サンプルサイズ**（データ行列の行数＝標本・観測の個数）、`p` = **変数の数**（列数＝特徴量の個数）。1 標本 = 観測 1 件。オミクスでは典型的に **n ≪ p**（例: n〜数百、p〜数万）。

遺伝子発現量・メチル化・タンパク質定量など、**説明変数が極めて多い**生体データでは次の課題がある。

| 課題 | 従来 EML-SR の弱点 | 本プロジェクトの方針 |
|------|---------------------|----------------------|
| 次元の呪い | p が大きく直接 SR では探索不能 | trunk で `p → d`（d ≪ p）に圧縮してから head で SR |
| 多重共線性 | 遺伝子間相関が高く不安定 | 層選択的学習で有効な部分空間に絞る |
| 解釈の要求 | ブラックボックス ML は臨床・論文で不受け入れ | 最終式は初等関数の閉形式 |
| **n ≪ p** | サンプルサイズ n に対し変数 p が圧倒的に多く過学習しやすい | 凍結層・浅い head・正則化・スパース化 |

#### 4.2 解釈の二層構造

生体データ向けには、次の**二段階の説明**を出力する設計とする。

1. **Trunk 寄与**: どの入力特徴（遺伝子・バイオマーカー）が潜在特徴 `z` の各成分に効いているか（重み・SHAP 等の補助解析）
2. **Head 式**: `ŷ = f(z)` の具体的な初等関数式（EML スナップ後）

最終的に「表型 ≈ 初等関数（遺伝子群の線形結合の非線形変換）」という**監査可能な式**を提示する。

#### 4.3 想定データセット（候補）

| データ | 特徴 | 用途 |
|--------|------|------|
| TCGA 等の公開オミクス | 遺伝子発現 × 臨床性状 | 実データでの proof-of-concept |
| 1000 Genomes / GWAS サマリ | 遺伝的変異 × 表現型 | 高次元・スパース構造 |
| 合成バイオデータ | 既知の生成メカニズム | 式回収率の ground truth 評価 |

※ データ取得・倫理審査・前処理パイプラインは Phase 4 着手時に別途設計する。

#### 4.4 Phase 4 専用の拡張（検討事項）

- **スパース trunk**: L1 / group lasso で遺伝子選択と次元圧縮を同時に
- **ドメイン正則化**: パスウェイ・遺伝子セット prior の組み込み
- **式の簡潔性ペナルティ**: 複雑すぎる EML 木を抑制（オッカムの剃刀）
- **外挿評価**: 未見サブタイプ・ホールドアウトコホートでの汎化

## 6. リスクと対策

| リスク | 対策 |
|--------|------|
| 層寄与の中間層集中が MLP trunk で再現しない | Phase 1 で早期検証。再現しなければ Boost/Only の対象を全層スキャンで決定 |
| EML の数値発散 | exp/ln クランプ、複素数演算の実部出力、学習率抑制 |
| 高次元 trunk の過学習 | d を小さく（例: d=4〜8）、Dropout、早期停止、層凍結 |
| 記号スナップ失敗 | D≤3 に制限、two-stage で trunk 収束後にスナップ |
| 生体データの **n ≪ p** 問題 | スパース正則化、既知バイオマーカーへの次元削減、外部コホート検証 |
