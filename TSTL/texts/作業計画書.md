## 2. 論文から読み取れるアルゴリズム仕様

### 2.1 問題設定（論文 §2–3）

- **対象**: 事前学習済み LLM の RL 後学習（主に GRPO）
- **疑問**: RL による改善は全層に均等に分布するか？
- **手法**: 層 `k` だけを学習し、他を凍結。全層学習（Full）と比較

パラメータ集合（論文式）:

```
θ = { θ_emb, θ_0, …, θ_{L-1}, θ_head }
```

単層学習（論文式 (3)）:

```
θ_k ← θ_k − α ∇_{θ_k} L_GRPO(θ)    （他パラメータは凍結）
```

勾配は全ネットワークを通るが、**更新は層 k のみ**。

### 2.2 層寄与 `C(k)`（論文 §2.2）

```
C(k) = (S_k − S_base) / (S_full − S_base)
```

| 記号 | 意味 |
|------|------|
| `S_base` | 学習前（ベース）モデルの in-domain 性能 |
| `S_full` | 全パラメータ学習後の性能 |
| `S_k` | 層 `k` のみ学習後の性能 |

解釈:

- `C(k) = 1.0` → 単層学習が Full と同等
- `C(k) > 1.0` → 単層学習が Full を上回る
- `C(k) ≈ 0` → その層だけでは RL 改善を捉えられない

### 2.3 主要知見（再現の合格ライン）

1. **中間層集中**: 高寄与層は深さの **40–60%** 付近に集中
2. **ランキング安定**: データセット・タスク・RL アルゴリズム間で Spearman ρ ≈ 0.6–0.8
3. **重み変化量との非一致**: Full 学習時の `‖Δθ_k‖` は層間でほぼ均一 → 寄与は「変化量」ではなく「部分空間の有効性」
4. **実用戦略**（論文 §4）が Full を上回る:
   - **Boost Bk**: 寄与上位 k 層の学習率を 2×（論文: 1e-5 vs 5e-6）
   - **Only Bk**: 寄与上位 k 層のみ学習
   - **Mid-k**: プロファイルなしで中間 k 層を選択（位置ヒューリスティック）

### 2.4 GRPO（論文 §2.1、参照のみ Phase 0）

Phase 0-B では GRPO 本体は実装せず、**同じ層選択手順が回ること**を MLP 教師あり学習で検証する。GRPO 接続は Phase 0-B+ で行う。

## 3. Phase 0-B における縮小再現方針

論文は LLM + GRPO だが、本リポジトリの Phase 0 出口基準（`README.md` §4）と NSN 統合（回帰 trunk）に合わせ、**MLP 教師あり回帰**で TSTL 手順を再現する。

| 論文（原文） | Phase 0-B（縮小） |
|--------------|-------------------|
| Transformer L 層 | MLP trunk L 層（3〜6 層） |
| GRPO 損失 | MSE 回帰損失（または分類なら CE） |
| `S` = ベンチマーク平均スコア（精度） | `S` = **負の MSE** または **R²**（§7 で固定） |
| NuminaMath-CoT | 合成多層回帰（非線形、ノイズ付き） |
| Qwen3-1.7B 等 | 2〜4 層 × width 64〜128 の MLP |

**合格条件（README Phase 0-B）**:

- `freeze_all_except(k)` が動作
- 3 層以上 MLP で `C(k)` ヒートマップを出力
- **中間層の `C(k)` が入出力端より高い傾向**を小規模でも観測（完全一致は不要）

## 7. 論文にない部分の設計判断（要承諾）

| # | 判断 | 理由 |
|---|------|------|
| 1 | **性能指標 `S` = R²**（回帰） | 解釈しやすく、NSN 回帰 trunk と整合。`C(k)` は `S` に対して計算 |
| 2 | **MLP で縮小再現**（Transformer ではない） | Phase 0 出口・NSN 統合が MLP trunk 前提。論文の層選択 *手順* を先に確立 |
| 3 | **GRPO は Phase 0-B では未実装** | 層寄与・凍結・戦略が主題。RL 損失は Phase 0-B+ |
| 4 | **層の定義 = MLP の各 Linear ブロック** | Transformer の `θ_k` に対応する最小単位 |
| 5 | **Boost 倍率 = 2×** | 論文 §4.1（lr 2:1）に準拠 |
| 6 | **Mid-k の k デフォルト = 3**（5 層 MLP 時） | 論文 §4.3 の 5 層相当（層 11–15 / L=28）をスケールダウン |
| 7 | **埋め込み・head 相当** | MLP では入力 Linear + 出力 Linear を「層」に含めるか、隠れ層のみか → **隠れ Linear のみを層と数える**（入出力は常に学習可 or 常に凍結を §7 追記で調整） |

**§7-7 補足（推奨）**: 隠れ層インデックス `k = 0 … L_h−1` のみを TSTL の「層」とする。入力・出力 Linear は Full / 単層学習時も **常に学習可能**（論文の `θ_emb`, `θ_head` が常に勾配を受けるのと同様）。単層実験では「隠れ層 k + head」のみ更新、他隠れ層凍結。

## 8. リスクと緩和

| リスク | 緩和 |
|--------|------|
| MLP では中間層集中が再現しない | タスクを非線形化（積・sin）、深さを 5〜6 に増加。それでも不可なら「手順実装完了・知見再現は Phase 0-B+」と記録 |
| 単層学習の `S_k` 計算コスト（L 回学習） | 層数 L≤6、steps 短縮のプロファイルモードを用意 |
| 論文の LLM 実験との数値一致は不可能 | 数値一致ではなく **C(k) プロファイル形状** と **戦略の相対順位** を目標に明記 |
| NSN ブランチとの作業競合 | ブランチ `20260713_create_TSTL` で `TSTL/` のみ編集 |
